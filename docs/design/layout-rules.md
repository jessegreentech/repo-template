# Layout rules

One section per page. Fill in before building the page.

## Template

### <Page name>

- Container: max width, padding at each breakpoint.
- Grid: columns at each breakpoint and gap.
- Reflow: what stacks, hides or moves at each breakpoint.
- Long content: what wraps, truncates (with ellipsis) or scrolls.
- Empty, loading and error states: what shows in each.
- Many items: pagination, scrolling or virtualisation.
